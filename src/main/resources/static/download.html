Get SignFlow for Windows

You need the SignFlow app on your computer to sign with your smart card. Sending and following documents works in the browser.

How to install it

  1. 1. Download and open the file

    Your browser will save it; open it when it finishes.

  2. 2. Install it

    If Windows shows a blue warning, choose More info, then Run anyway. The installer is not yet signed, so Windows does not recognise it.

  3. 3. Plug in your card reader

    Then come back to this website and press Sign on the document waiting for you.

Something went wrong?
The four things that usually explain it.

What you need
  • Windows 10 or 11, 64-bit
  • A smart card reader
  • Your card's own driver installed

Nothing else: the app brings its own Java runtime.

Already installed? Go to your documents and press Sign now on the one waiting for you.
